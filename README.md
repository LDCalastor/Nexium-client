## ◆ Présentation

**Nexium Client** repense l'expérience Discord du sol au plafond. Là où le client officiel reste fermé, Nexium ouvre tout : interface, performances, apparence. Le tout livré clé en main, sans installateur tiers à empiler.

Au cœur du client : **Nexium Mods**, le moteur d'extensions qui regroupe plugins, thèmes et optimisations dans un seul ensemble cohérent.

## ◆ Fonctionnalités

| | Module | Description |
|---|---|---|
| 🧩 | **300+ plugins** | Bibliothèque orientée confort : QoL, raccourcis, customisation d'interface, prévisualisations enrichies. Chaque plugin est activable / désactivable à la volée. |
| 🎨 | **Thèmes sur-mesure** | Refonte complète de l'apparence — palettes, typographies, layout, effets. Importez un thème de la communauté ou écrivez le vôtre en CSS, rechargé en direct. |
| ⚡ | **Optimisation** | Réglages de rendu et allègements pensés pour une interface plus fluide et une empreinte mémoire réduite. |
| 🌐 | **Bilingue FR / EN** | Interface entièrement traduite, français et anglais. |
| 💸 | **100 % gratuit** | Aucun paiement, aucun abonnement. Téléchargement libre. |

## ◆ Installation

> [!IMPORTANT]
> Ne téléchargez Nexium Client **que** depuis ce dépôt officiel. Toute autre source peut être altérée.

```bash
git clone https://github.com/LDCalastor/Nexium-client.git
```

1. **Téléchargez** le build depuis ce dépôt (`Releases` ou `git clone`).
2. **Lancez** l'installateur — Nexium Mods, les thèmes et les optimisations sont intégrés d'office.
3. **Personnalisez** : activez vos plugins, chargez un thème, ajustez l'accent depuis le client.
